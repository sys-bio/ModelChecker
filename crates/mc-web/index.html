Model Checker

Model Checker finds mistakes in kinetic (ODE) models written in SBML. Simulators will run a model whose rate law divides by zero when a species runs out, whose reactions keep consuming a species after it is gone, or whose units do not add up. The result is a simulation that fails part way through, concentrations that go negative, or, worst of all, an answer that is quietly wrong. Model Checker reads the model and examines every rate law and rule without simulating it. It explains each problem it finds and, where it can, gives a concrete set of values that shows it.

Use it while building a model, before publishing one or submitting it to a repository such as BioModels, when reviewing or curating someone else's model, or when a simulation misbehaves and you want to rule out the model itself. It looks for:

  • Singular rate laws: division by zero, logs of zero, and the like, at the initial values or at any state the model could reach.
  • Species that can go negative: reactions that still consume a species once it has run out, including reactions written in the opposite direction to their rate law.
  • Zero-order reactions and reactants missing from rate laws, which are often typos.
  • Unit errors: rate laws not in amount per time, missing compartment volume factors, and sums of quantities with different units.
  • Symbol problems: undefined, unused, or valueless parameters and species.

What is checked

Species are assumed to be non-negative concentrations (unless they start negative), parameters fixed at their values, and function definitions and assignment rules are expanded into the rate laws that use them. Each rate law is analysed with interval arithmetic over all such states, then searched for concrete counterexamples, which are shown as witnesses. States that would empty a conserved moiety are excluded. The reversible attribute is ignored: the rate law alone decides which way a reaction can run.

About Model Checker

Model Checker runs static checks on kinetic SBML models (Levels 2 and 3), entirely in your browser: the model is never uploaded. It is written in Rust and compiled to WebAssembly. Version .

Source code, the command-line tool, and issue tracker: github.com/sys-bio/ModelChecker.
